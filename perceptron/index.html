퍼셉트론 논리 연산 실험실

가중치와 편향이 만드는 직선으로 논리 연산을 구현하고, 학습 규칙과 배타적 논리합까지 탐구합니다.

1장기본 논리 연산 2장가중치 학습 3장배타적 논리합

① 가중치와 편향 정하기
조절 단위

    ② 좌표평면에서 확인하기
    • 법선벡터 (w1, w2) 방향
    • 목표 출력 1인 입력
    • 목표 출력 0인 입력
    • 고리: 출력 1
    • 고리: 출력 0
    x1x2 z출력 y목표판정

    ① 학습 과정 따라가기

    wi ← wi + (t − y)xi,  b ← b + (t − y)

    t: 목표 출력(정답), y: 퍼셉트론이 낸 출력, t − y: 오차, xi: 입력

    ② 직선이 움직이는 모습
    • 목표 1
    • 목표 0
    • 고리: 지금 출력 1
    • 고리: 지금 출력 0
    • 갱신 전 직선
    ③ 학습 기록
    갱신이 일어난 줄은 색으로 표시됩니다.
    바퀴입력목표 t출력 y오차 t−y w1w2b

    ① 뉴런을 골라 가중치와 편향 정하기
    편향

    힌트배타적 논리합은 "NAND와 OR의 결과를 AND로 묶은 것"과 같습니다. 1장에서 찾은 값을 뉴런 세 개에 나누어 넣어 보세요.

      ② 두 평면에서 확인하기

      입력 평면의 색 띠는 각 직선의 법선벡터 방향(출력 1인 쪽)입니다. 은닉 평면의 점은 각 입력이 (h1, h2)로 옮겨진 위치이고, 옆의 "입력 (…)"은 원래의 (x1, x2)입니다. 같은 자리로 옮겨진 입력은 점 하나로 표시합니다.

      ③ 배타적 논리합(XOR) 결과표
      x1x2 h1h2 출력 y목표판정
