# 협의회 등록부(서명부) 웹앱 — Google Apps Script

참석자가 휴대폰으로 **소속·직위·성명·계좌번호**를 입력하고 화면에 **서명**하면,
구글 시트에 한 줄씩 기록됩니다. 서명은 셀 안 이미지로 바로 보입니다.

| 연번 | 소속 | 직위 | 성명 | 계좌번호 | 서명 | 등록시각 |
|---|---|---|---|---|---|---|
| 1 | 경북대사대부고 | 교사 | 홍길동 | (농협) 302-0000-0000-00 | ✍️ (이미지) | 2026-10-20 17:31:05 |

## 설치 방법

1. 새 구글 스프레드시트 만들기
2. **확장 프로그램 → Apps Script** 열기
3. `Code.gs` 내용을 붙여넣기
4. **파일 추가(+) → HTML** → 이름을 `Index`로 만들고 `Index.html` 내용 붙여넣기
5. `Code.gs` 맨 위 `CONFIG`의 제목·일시·장소를 회의에 맞게 수정
6. 함수 목록에서 `setupSheet` 선택 → **실행** (처음 한 번 권한 승인)
7. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (구글 로그인 없이 서명 가능)
8. 나온 웹앱 URL을 QR코드로 만들어 협의회 장소에 비치

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다.

## 동작 메모

- 같은 **소속 + 성명**으로 두 번 등록하면 막습니다. (잘못 등록한 경우 시트에서 행을 지우고 다시 등록)
- 동시에 여러 명이 제출해도 `LockService`로 연번이 겹치지 않습니다.
- 서명 원본 PNG는 드라이브 `협의회 서명 이미지` 폴더에도 보관됩니다.
- 셀 이미지 삽입이 실패하는 환경이면 자동으로 `=IMAGE()` 수식으로 대신 표시합니다.
  (이때 해당 서명 파일은 '링크가 있는 사용자 보기'로 공유됩니다.)
- 계좌번호 열은 텍스트 형식이라 앞자리 `0`이 사라지지 않습니다.
