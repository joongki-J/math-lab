# 모니터링 검토 웹앱 (Google Apps Script)

'NEW모니터링 양식' 시트의 C열 문항을 모바일에서 한 페이지씩 보며
A/B/C 수준 설명(D·E·F열) 중 하나를 골라 G열(검토 결과)에 기록하는 웹앱입니다.

## 설치
1. 엑셀 파일을 구글 드라이브에 올려 **Google 스프레드시트로 열기**(변환)
2. 스프레드시트 메뉴 **확장 프로그램 > Apps Script**
3. `Code.gs` 내용을 붙여넣고, **+ > HTML** 로 `index` 파일을 만들어 `index.html` 내용 붙여넣기
4. **배포 > 새 배포 > 웹 앱** — 실행 사용자: 나 / 액세스: 나만(또는 조직 내 사용자)
5. 나온 웹앱 URL을 휴대폰에서 열기 (홈 화면에 추가하면 앱처럼 사용 가능)

시트 이름이 다르면 `Code.gs`의 `CONFIG.SHEET_NAME`을 수정하세요.

## 기능
- 문항 1개 = 1페이지, 좌우 스와이프 / 이전·다음 버튼
- A·B·C 선택 시 G열에 즉시 저장 후 다음 문항으로 자동 이동 (다시 누르면 '검토중'으로 해제)
- 각 선택지에 1행의 일반 수준 설명을 함께 표시 (숨기기 가능)
- 검토 노트(H열) 자동 저장
- ☰ 목록에서 전체 진행 상황 확인 및 원하는 문항으로 이동
- 마지막 페이지에서 모니터링 종합의견(C열 병합 셀) 편집
