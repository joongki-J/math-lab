# 중기쌤의 수학 실험실 — 도구 제작 규칙

이 저장소는 고등학교 수학 수업에서 교실 화면에 바로 띄우는 인터랙티브 도구 모음입니다.
도구마다 다루는 수학은 다르지만 **껍데기(상단바·패널·버튼·색)는 전부 같아야** 합니다.
학생과 교사가 도구를 옮겨 다닐 때 같은 사이트라는 느낌이 유지되어야 하기 때문입니다.

작업 전에 저장소 루트의 `agent.md`도 함께 읽으세요. 커밋·확인 절차가 거기 정리되어 있습니다.

## 새 도구를 만들 때

1. **템플릿에서 시작합니다.** `assets/tool-template.html`을 `<도구폴더명>/index.html`로 복사하세요.
   상단바·패널·버튼·반응형이 이미 올바르게 들어 있습니다. CSS를 기억에 의존해 새로 쓰면
   색이 한두 단계씩 어긋나고, 아래 "자주 깨지는 곳"의 함정을 그대로 밟게 됩니다.
   ```bash
   mkdir -p <도구폴더명>
   cp .claude/skills/math-lab-tool/assets/tool-template.html <도구폴더명>/index.html
   ```
2. `[[...]]` 자리표시자를 채웁니다: 제목, 과목·분류(eyebrow), 한 줄 설명, 패널 제목.
3. 도구 로직과 도구 전용 CSS를 채웁니다. 도구 전용 CSS는 템플릿 맨 아래
   `/* ===== 도구 전용 CSS는 여기부터 ===== */` 아래에만 추가하고, 위쪽 공통 셸은 건드리지 마세요.
4. 메인 목록에 등록합니다(아래 "등록하기").
5. 브라우저로 확인합니다(아래 "확인하기"). **확인 없이 완료라고 말하지 마세요.**

도구는 폴더 하나에 `index.html` 한 장으로 끝내는 자체 완결형입니다. 지금까지의 도구가 모두
그 구조이고, GitHub Pages에서 빌드 없이 바로 열리는 이유이기도 합니다.

## 디자인 토큰

템플릿을 쓰면 자동으로 적용되지만, 도구 전용 CSS를 쓸 때 참고하세요.

| 용도 | 값 |
|---|---|
| 배경 | `#f2f0e9` + 34px 격자 라인 |
| 패널 | `#fbf9f3` (연한 면은 `#f4f1e9`) |
| 보더 | `#d8d2c7` (옅게: `#eee9df`) |
| 본문 글씨 | `#15171a` / 보조 `#6b6f74` / 흐리게 `#9a958a` |
| 포인트(오렌지) | `#ff5a30` — 패널 제목 막대, eyebrow 선, 강조 |
| 형광(라임) | `#d9f24f` — `h1 em` 밑줄 하이라이트 등 아껴서 |
| 진한 면 | `#15171a` — primary 버튼, 배지, 수식 상자 |
| 그림자 / 곡률 | `0 10px 28px rgba(21,23,26,.055)` / `16px` |
| 글꼴 | `Pretendard,"Apple SD Gothic Neo","Noto Sans KR",...` + `letter-spacing:-.015em` |

**다크 모드는 없습니다.** 단일 웜 테마 하나만 씁니다. 도구 페이지에 테마 토글을 넣지 마세요
(이전에 한 도구가 자체 다크 모드를 갖고 있었고, 사이트에서 혼자 튀어서 걷어냈습니다).
Pretendard는 CDN으로 불러오지 않고 시스템 폰트 폴백으로 씁니다 — 메인과 동일한 방식입니다.

## 반드시 같아야 하는 구조

- **상단바**: 원형 `←` + `중기쌤의 수학 실험실` / `MATHEMATICS LABORATORY` → 세로 구분선 →
  eyebrow(오렌지 짧은 선 + 과목·분류) → `h1` → `subtitle`. 오른쪽 다크 알약 배지는 선택입니다
  (상태가 없는 도구면 지우세요).
- **홈 링크는 `../#tools`** 입니다. 메인의 도구 목록 위치로 정확히 돌아가기 위해서입니다.
- **패널**: `.panel` > `.panel-head`(`.panel-title` + `.panel-desc`) > `.panel-body`.
  패널 제목에는 왼쪽 3px 오렌지 세로 막대가 붙고, 여러 단계를 오갈 때 `①②③`으로 번호를 답니다.
- **버튼**: 알약(`border-radius:999px`), hover 시 살짝 떠오름. 주 동작만 `.btn.primary`(검정).
- **그림 영역**: 흰 배경 + `1px #e3ded4` 보더 + `12px` 곡률(`.chart-wrap`). 격자 배경 위에
  캔버스를 그대로 올리면 그래프가 지저분해집니다.

## 레이아웃은 도구에 맞게 정하세요

위 목록은 **껍데기**만 고정합니다. 패널을 몇 개 두고 어떻게 배치할지는 그 도구가 무엇을
보여주는지에 따라 자유롭게 정하세요 — 기존 도구도 서로 다릅니다.

- 경사하강법 시각화(`gradient-descent-1`, `-2`)는 **4단**입니다:
  자료 입력 → 그래프 → 그래프 → 설정. 입력과 결과를 한 화면에서 동시에 보여줘야 하는 도구입니다.
- 시에르핀스키(`sierpinski`)는 **2단**입니다: 넓은 그림 영역 + 좁은 설정 영역.
  볼 것이 하나뿐인 도구라 단을 더 쪼갤 이유가 없습니다.

템플릿은 2단으로 시작하니 필요하면 `.workspace`의 `grid-template-columns`를 바꾸세요.
바꿀 때 지킬 것은 두 가지입니다.

- 각 칸에 `minmax(<최소폭>, <비율>fr)`로 최소 폭을 주세요. 최소 폭이 없으면 창이 좁아질 때
  그래프가 읽을 수 없을 만큼 찌그러집니다.
- **좁아지면 단을 접으세요.** 2단은 900px에서 한 번에 1단으로 갑니다. 3~4단은 한 번에
  1단으로 가면 세로로 너무 길어지므로 두 번 접습니다 — 경사하강법 도구는 1350~1500px에서
  2단으로, 820~880px에서 1단으로 떨어집니다. 접힐 때 화면 높이를 채우도록
  `grid-auto-rows`를 함께 주는 방식도 그 도구들에 쓰여 있으니 참고하세요.

## 자주 깨지는 곳

- **`.topbar`에 `align-items:stretch`를 쓰지 마세요.** 알약 배지(`border-radius:999px`)가
  줄바꿈된 제목 높이만큼 세로로 늘어나 거대한 검은 원이 됩니다. 실제로 모바일에서 터졌던 버그입니다.
  820px 이하에서는 `align-items:flex-start` + `.badge{display:none}`로 갑니다.
- **반응형 3단은 템플릿 그대로 두세요**: 1080px(brand small 숨김) / 820px(배지·구분선·brand 숨김,
  `h1` 줄바꿈 허용) / 520px(여백 축소, `h1` 20px, 버튼 `min-height:40px`).
- **모바일 가로 스크롤**: 표·그래프처럼 좁힐 수 없는 요소는 각자 `overflow-x:auto` 컨테이너에
  넣으세요. 페이지 자체가 가로로 밀리면 안 됩니다(확인 스크립트가 잡아 줍니다).

## 등록하기

도구 페이지만 만들면 메인에서 보이지 않습니다. `script.js` 맨 위 `TOOLS` 배열에 추가하세요.

```js
{
  title: "시어핀스키 삼각형 탐구",
  subject: "미적분Ⅱ",          // 아래 목록에 있는 값만
  symbol: "△",                 // 썸네일이 없을 때 쓰는 대체 기호
  description: "반복 규칙이 만들어내는 프랙탈 구조와 자기유사성을 탐구합니다.",
  tags: ["프랙탈", "반복", "도형"],
  url: "./sierpinski/"          // 폴더명과 정확히 일치
}
```

- **배열 순서가 화면 순서**입니다. 카드 번호(01, 02…)는 순서대로 자동으로 매겨집니다.
- **`subject`는 `SUBJECT_GROUPS`에 있는 값만** 씁니다. 목록에 없는 값을 쓰면 어떤 과목 칩으로도
  걸러지지 않아 학생이 찾지 못합니다:
  `수학1` `수학2` `수학3` / `공통수학1` `공통수학2` /
  `대수` `미적분Ⅰ` `미적분Ⅱ` `확률과 통계` `기하` `인공지능 수학` `경제 수학` `수학과제 탐구` / `업무`
- **같은 `url`을 가리키는 항목이 둘 이상 있으면 안 됩니다.** 실제로 한 폴더를 가리키는 항목이
  둘 있었고, 그중 하나는 설명이 전혀 다른 도구 것이었습니다. 추가·수정 후 한 번 확인하세요.
- **썸네일**은 `thumbnails/<도구폴더명>.png`입니다(`jpg`→`png`→`jpeg`→`webp` 순으로 자동 탐색).
  카드에서 `object-fit:cover`로 잘리므로 가로로 넓은 비율이 좋고, 없으면 `symbol` 기호가 나옵니다.

## 확인하기

바꾼 뒤에는 실제 브라우저로 봅니다. 이 환경에는 Playwright와 Chromium이 설치되어 있고,
번들된 스크립트가 정적 서버·스크린샷·콘솔 에러·가로 스크롤 검사를 한 번에 처리합니다.

```bash
node .claude/skills/math-lab-tool/scripts/preview.mjs <도구폴더명>   # 도구 페이지
node .claude/skills/math-lab-tool/scripts/preview.mjs .              # 메인 목록
```

찍힌 PNG를 **Read로 직접 열어 눈으로 확인하세요.** 스크립트는 에러와 넘침만 잡을 뿐,
색이 어긋났는지 여백이 이상한지는 보지 못합니다. 확인할 것:

- 데스크톱·모바일 두 폭 모두에서 상단바가 멀쩡한가(특히 배지)
- 메인 목록에서 카드 순서·과목 라벨·썸네일이 의도대로인가
- **기존 도구들이 그대로 동작하는가** — 공통 CSS나 `script.js`를 건드렸다면 반드시 함께 보세요

## 작업 원칙

- **메인 페이지의 디자인과 기존 기능은 임의로 바꾸지 않습니다.** 새 도구를 추가하려고
  `style.css`나 메인 레이아웃을 고쳐야 할 것 같으면, 그대로 진행하지 말고 먼저 사용자에게 물어보세요.
- **요청받은 것만 고칩니다.** 도구 하나의 디자인을 고쳐 달라는 요청에 다른 도구까지 손대지 마세요.
  개선할 점이 보이면 먼저 끝내고 나서 제안하세요.
- **GitHub Pages(https://joongki-j.github.io/math-lab/)에서 돌아갑니다.** 빌드 단계가 없으므로
  경로는 상대경로로, 외부 라이브러리는 버전을 고정한 https CDN으로 불러오고 실제로 로드되는지
  확인하세요. 로드에 실패해도 페이지가 통째로 죽지 않게 하는 편이 안전합니다.
- 커밋은 `agent.md`의 절차를 따릅니다.
